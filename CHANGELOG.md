# Changelog

## 1.6.2-SNAPSHOT — подготовка репозитория

- Разделены Gradle-модули `core`, `fabric`, `editor`. Числовое ядро выпускается отдельной Java-библиотекой без Minecraft.
- Сохранены имена Java-пакетов, семантика формул и форматы JSON/NBT/редактора.
- Математический backend EvalEx/Spire перенесён без изменений. Основной мод включает core; demo по-прежнему отдельный необязательный JAR.
- Добавлены сборка без Minecraft, проверки границ, документация и GitHub Actions.
- Из публикуемого дерева исключены старые сборки, экспериментальные backend, машинные кэши, миры и исторические журналы. Актуальные регрессионные тесты сохранены.

## 1.6.1 — исходная функциональная база

- Редактор показывает отдельные входные списки, выходные значения и формулы; настройки доступны через меню и диалог полей.
- Поддержаны обозначения параметров, несколько входов, экспорт серверного каталога с резервной копией и учебные цепочки.
- Данные предметов хранятся как int32-сотые по постоянным ID. Производственная линия сохраняет подтверждённые входы и готовый выход.
