# Изменения проекта

Для работы нужен JDK 17. Изменяйте исходники нужного модуля и запускайте проверки из [docs/development.md](docs/development.md).

- Числовое ядро не должно зависеть от Minecraft, Fabric или редактора.
- Используйте существующие EvalEx/Spire. Не добавляйте собственный парсер, арифметику корней/дробей или второй вычислитель.
- Сохраняйте точные промежуточные результаты и усечение только на выходной границе.
- Не меняйте ID сохранённых полей, JSON/NBT и публичные Java API без описания совместимости и миграции.
- Изменения числовой семантики, допуска предметов и сохранения требуют соответствующих регрессионных проверок.
- Обычный production-цикл использует сохранённый результат. Не переносите компиляцию/вычисление формул в каждый тик механизма.
- Не коммитьте игровые миры, кэши, сборки, личные настройки, токены и локальные пути.

Описание pull request должно объяснять, что изменилось для пользователя/API, почему это нужно и какие проверки прошли. Если проверка не выполнена, укажите это явно.
