# Проверка разделения модулей — 18.10.2026

Функциональная база — исходники 1.6.1. В новом репозитории версия разработки `1.6.2-SNAPSHOT`. Все 85 перенесённых Java-файлов сопоставлены с исходником: кроме нормализации переводов строк/пустых строк в конце содержимое сохранено. Числовой backend не переписывался.

Локально использованы JDK 17.0.20 и Gradle 8.10.2. Зависимости взяты из существующего кэша в offline-режиме; для особенностей этого ПК использовался внешний init script. Эти машинные пути и init script в репозиторий не добавлены. Свежая загрузка зависимостей на другом ПК и GitHub Actions этим запуском не подтверждаются.

| Исполняемый editor JAR | Дополнительно 45 проверок формул, сохранения/экспорта и отрисовки через прежний внешний проверочный сценарий |

Основная команда — `build`; для независимой сборки — `-Pstandalone=true build`. Исполняемый редактор проверен из собранного JAR, а не только из каталога компиляции.

Эта проверка подтверждает сборку, существующие регрессионные сценарии и упаковку. Она не является новым замером TPS, скорости старой/новой версии или вместимости игрового мира. Установленная игровая сборка и сохранения при подготовке репозитория не менялись.
