# Работа с редактором

Редактор — отдельная программа Java 17. Он не требует запущенного Minecraft. Откройте исполняемый `item-parameters-editor-<version>.jar` либо запустите `./gradlew -Pstandalone=true :editor:run`.

## Первый пример

1. В меню **«Файл»** откройте `examples/tutorial/Практика.ipproject`.
2. Выберите рецепт плавки. В левой части находится входной предмет, в правой — выходной. Для нескольких входов редактор показывает отдельные списки.
3. В таблице входа находятся обозначение, название поля и пробное значение. Пробное значение нужно для проверки формулы в редакторе.
4. Кнопка **«Поля…»** открывает начальные значения и допустимые диапазоны предмета. Это настройки для игры; они отличаются от пробных чисел.
5. В нижней части записываются формулы, по одной записи на строку.
6. Нажмите **«Рассчитать»**. Справа появятся результаты для указанных пробных значений. Это ещё не меняет игру.

## Обозначения и записи

Поля могут называться по смыслу: «Масса», «Чистота», «Прочность». Для записи в формуле назначьте короткие обозначения: `M`, `P`, `H`, греческую букву или другой допустимый символ. Можно использовать номера строк.

Каждое обозначение входа относится к конкретному полю конкретного входного предмета. Если масса есть у трёх предметов, назначьте ей `M1`, `M2`, `M3`, чтобы ссылка была однозначной.

```text
(M1 + M2 + M3) * [0.95] = M
sqrt(H ^ [2] + K ^ [2]) = R
root(M1 + M2, [3]) = S
[25] = H
```

Слева от `=` — выражение, которое читает поля входов. Справа — обозначение или номер поля **выходного предмета**. Входной `M` и выходной `M` могут совпадать по написанию: сторона равенства определяет их назначение. Выходные поля сначала объявляются в правом списке; формула не создаёт поле из опечатки.

Постоянные числа пишутся в квадратных скобках: `[100]`, `[0.95]`. Обычная положительная целая цифра без скобок означает номер строки входного списка. Например, `1 * 2 = 3` читает входные строки 1 и 2 и записывает результат в выходную строку 3.

Разные строки формул читают исходные входы. Запись `M = A`, затем `A + [1] = B` не создаёт промежуточную переменную `A`: слева `A` тоже должен быть входным полем. Для последовательной обработки используйте следующий рецепт или повторите нужное выражение.

Полям без формулы назначается выбранное в редакторе правило: начальные значения выхода либо перенос общих полей из указанного входа. Список входов и выбранные Item ID определяют, сколько компонентов требует рецепт; один выходной предмет может получить данные от нескольких входов.

## Передача в игру

Сохраните `.ipproject`, затем нажмите **«Передать в Minecraft…»** и выберите папку игры/сервера, в которой находится `config`. Редактор устанавливает весь каталог в `config/itemparams/`, предварительно создавая резервную копию предыдущего. Это операция настройки сервера, а не команда обычного игрока.

Перезапустите мир/сервер. Текст формул в `.ipproject` редактор преобразует в техническую запись с именами входов и ID полей. Писать JSON вручную для обычной работы с редактором не требуется. [Описание файлов](configuration.md) предназначено для тех, кому удобнее редактировать каталог вручную или генерировать его из своей системы.

В игре нельзя изменять формулы стандартным интерфейсом основы. Необязательный demo-станок позволяет выбрать уже настроенный рецепт и проверить обработку. Основной мод не подключает рецепты автоматически к обычной печи.
